# Kalkulator poligraficzny KHOREI

Wyceny, impozycja i cięcie arkusza dla drukarni. Copyright © 2026 Radosław Prośniak (KHOREI) — patrz LICENSE.

Uruchomienie lokalne: `python3 -m http.server` w katalogu, potem http://localhost:8000.
Testy: `node --test tests/*.test.mjs`.

Publikacja: każdy push na `main` → testy → GitHub Pages (workflow `.github/workflows/pages.yml`, numer wersji nadawany automatycznie).
